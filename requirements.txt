# --- Scientific/ML stack: minimum versions instead of exact pins ---
# The original exact pins here (scikit-learn 1.5.1, numpy 1.26.4,
# scipy 1.14.0, pandas 2.2.2) all predate prebuilt Python 3.13 wheels
# being published (scikit-learn added cp313 wheels in 1.6.0; numpy in
# 2.1.1; pandas in 2.2.3; scipy in ~1.14.1). Pinning to those exact
# versions forces pip to compile from source on Python 3.13, which
# needs a full C/C++/Fortran + Cython + Meson toolchain and fails on
# most Windows machines with only a basic/older compiler installed —
# this is exactly the error a user hit running `pip install -r
# requirements.txt` on Python 3.13/Windows. Using >= here lets pip pick
# the latest compatible wheel instead of trying to build 1.5.1 from
# source. See docs/PROJECT_WORKFLOW.md's "Post-delivery fixes" section
# for the real report this was fixed from.
