## Contributing to Documentation

When making changes to the platform, please update the relevant documentation:

1. **API Changes**: Update `api-documentation.md`
2. **New Features**: Update relevant sections in `architecture-overview.md`
3. **Platform Support**: Update `platform-integrations.md`
4. **Deployment Changes**: Update `deployment.md`

## Support

For questions about the platform:

1. Check the relevant documentation first
2. Review the troubleshooting guide
3. Check the GitHub issues (if available)
4. Contact the development team

## Documentation Standards

- Use clear, concise language
- Include code examples where helpful
- Follow Markdown formatting standards
- Keep documentation up-to-date with code changes
- Use relative links for internal references
